# Evaluation review

Reviewer: architecture/evaluation agent. Initial review: 2026-10-28, Asia/Taipei. This review covers protocol and synthetic checks; it contains no real-data predictive result.

The primary experiment holds out model identities and detected underlying-item groups. It permits only selected support labels from a new model and excludes every training model's final target labels. Fixed-bank experiments have a different information boundary and must remain in a separate table.

The grouping-v2 target is 22,475 deterministic prompt representatives from five sources and 88 lineage-audited models. The structural rule uses row counts/category identity rather than correctness. Its singleton pattern happens to be identical across all 112 released models. The retained target remains a retrospective proxy: evaluator revisions, generation settings, scoring filters, and upstream failure handling are unresolved. It does not recover official benchmark scores or prospective deployment validity. Complete-stem unions reduce known duplicate leakage but can overgroup generic stems; unrecognized paraphrases can remain.

The paired family design preserves target IDs, validation Qwen IDs, item splits, static probe IDs, and 40 training models. Swapping related models for the same count of unrelated replacements controls training volume and target composition. It remains an ancestry-composition comparison because the swapped models differ in other characteristics. Adaptive probe changes introduce an additional acquisition component; balanced random is the core matched comparison.

The metric implementation gives benchmarks equal weight within each model, then models equal weight. Per-item proper scores use the same observed response mask as score errors. Missing benchmarks are rejected in the primary scorer. The bootstrap averages seed-level metrics within model before resampling paired models or whole reviewed lineage clusters. A single-family target has no estimable lineage bootstrap interval; intervals based on two or three blocks remain descriptive. Score MAE of averaged probabilities would describe a different ensemble estimand and is not silently substituted.

The within-benchmark response permutation is a valid negative control when performed separately on each already-revealed budget prefix. It preserves every domain's response total and NaN mask, and never imports later responses. Rank-zero MAP latents, covariance, and predictions remain invariant because its response feature vector is constant within a benchmark; its scalar objective need not remain equal.

The following owned checks passed with `python -m pytest tests/test_metrics.py tests/test_evaluation_leakage.py -q`: 22 tests. They cover macro versus micro weighting, opposing benchmark errors, missing-label denominators, bounded probabilities, seed pseudo-replication, paired cluster resampling, model/group overlap, label-invariant splitting, manifest tampering, benchmark/item coverage, template/option variants, prefix-only permutation, rank-zero MAP invariance, and the three paired family swaps.

Pre-lock integration review identified four issues for the experiment owner to resolve: enforce audited-model filtering before singleton selection; honor the fixed 64-per-domain training reference and nested Fisher config; preserve acquisition/reference ID traces; and bind the test lock to source code and actual prepared-data hashes. Joint family hyperparameter selection must use the mean validation result of both arms. Resolution must be checked against the saved lock and outputs before any result is accepted.

Real-data acceptance will require checking the locked target and split hashes, selected validation settings, complete seed/method coverage, matching per-policy probe IDs across predictors, MAP convergence, reference/probe membership in training items, and interpretation of paired differences. Those checks remain pending at this review stage.
